## Sheet: Checklist

| Control                   | Requirement                                            | Mandatory for                  |
|---------------------------|--------------------------------------------------------|--------------------------------|
| ISO 27001 certificate     | Valid certificate or equivalent SOC 2 Type II report   | Tier 1 and Tier 2 vendors      |
| Data Processing Agreement | Signed DPA before any personal data is shared          | Vendors handling personal data |
| Penetration test report   | Report dated within the last 12 months                 | Tier 1 vendors                 |
| MFA on vendor accounts    | MFA enabled on all accounts accessing NexaCore systems | All vendors with system access |

## Sheet: Risk Tiers

| Tier   | Definition                                             | Reassessment frequency   |
|--------|--------------------------------------------------------|--------------------------|
| Tier 1 | Access to customer personal data or production systems | Every 12 months          |
| Tier 2 | Access to internal data only                           | Every 24 months          |
| Tier 3 | No data or system access                               | At onboarding only       |
